# Future Leader Logistics Dashboard

A premium logistics dashboard built with **Next.js + Tailwind CSS**.

## Features

- Sidebar navigation with active route states (**Dashboard**, **Shipments**, **Analytics**)
- SaaS-style glassmorphism layout and premium controls
- KPI dashboard cards with trend badges
- Shipment tracking input with instant status lookup and journey progress
- Responsive shipments table with lane and progress visualization
- Dedicated pages for dashboard, shipment operations, and analytics summaries
- Futuristic blue/purple gradients, hover transitions, and motion effects

## Routes

- `/` → Dashboard
- `/shipments` → Shipment monitoring page
- `/analytics` → Analytics page

## Getting Started

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
